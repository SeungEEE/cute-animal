# 🐾 재밌는 사이트 모음

> 우리 팀이 직접 고른, 심심할 때 하나씩 눌러보는 사이트 모음집

깃허브 특강 1~2일차(2026.09.17 ~ 09.18) 팀 프로젝트로 제작된 정적 웹페이지입니다. 카드 형태의 그리드 레이아웃으로 팀원들이 추천한 귀여운 동물 영상 페이지들을 모아 소개합니다.

## 📌 소개

메인 페이지(`index.html`)에서 각 카드를 클릭하면 팀원별로 추천한 동물 영상 페이지(`sites/` 폴더)로 이동합니다. 순수 HTML/CSS로 제작되었으며, 카드 블록을 복사·붙여넣기만 하면 새로운 항목을 쉽게 추가할 수 있는 구조로 설계되었습니다.

## 📁 폴더 구조

```

├── index.html        # 메인 페이지 (카드 목록)

└── sites/             # 개별 추천 페이지 모음
```

## 🚀 실행 방법

별도의 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

```bash
git clone <저장소 주소>
cd cute-animal
open index.html   # 또는 브라우저에서 직접 열기
```
